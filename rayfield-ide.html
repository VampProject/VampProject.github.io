Welcome to Rayfield IDE

This is a comprehensive Web IDE for building beautiful GUIs with the Roblox Rayfield Framework.

Creating Your First Window

To create a window, use the Window widget from the sidebar and configure its properties.

local Window = Rayfield:CreateWindow({ Name = "My Window", Icon = 0, LoadingTitle = "Loading...", LoadingSubtitle = "by VampProject" })
Adding Widgets

Drag widgets from the sidebar to add them to your window. Customize properties on the left panel.

Keyboard Shortcuts

  • Ctrl+Z: Undo
  • Ctrl+Y: Redo
  • Ctrl+F: Find

❓ Getting Started

Quick Start Guide

  1. Create a new project or choose a template
  2. Drag widgets from the sidebar to the visual builder
  3. Customize properties in the right panel
  4. Write code in the editor
  5. Click Run to test your GUI
  6. Export your code when ready
